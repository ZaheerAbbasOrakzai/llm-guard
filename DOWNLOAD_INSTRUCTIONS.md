# 📥 DOWNLOAD INSTRUCTIONS

## How to Get Your Project Files

### Option 1: Download ZIP (Recommended)
Look for a **"Download"** or **"Export"** button in this tool's interface.
- Click it to download a ZIP file
- Extract the ZIP to your Desktop or Documents folder

### Option 2: Copy Files Manually
If there's no download button, you'll need to copy the code manually:

1. **Create a new folder** on your Desktop called `llm-guard`
2. **Copy each file** from this project into that folder
3. Make sure to maintain the folder structure:
   ```
   llm-guard/
   ├── src/
   │   ├── components/
   │   ├── data/
   │   ├── store/
   │   ├── App.tsx
   │   ├── main.tsx
   │   └── index.css
   ├── README.md
   ├── package.json
   ├── tsconfig.json
   ├── vite.config.js
   └── ... (all other files)
   ```

## After Downloading

### Step 1: Open Terminal
Navigate to your extracted folder:
```bash
cd Desktop/llm-guard
```
(or wherever you extracted it)

### Step 2: Open in VS Code
```bash
code .
```

### Step 3: Install Dependencies
In VS Code terminal (press `Ctrl+~`):
```bash
npm install
```

### Step 4: Push to GitHub
Run these 6 commands one by one:

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "🚀 Initial commit: LLM Guard - Production-Grade Model Regression Detection System"
```

```bash
git remote add origin https://github.com/ZaheerAbbasOrakzai/llm-guard.git
```

```bash
git branch -M main
```

```bash
git push -u origin main
```
