## 📥 How to Use These Images

### Option 1: Use URLs Directly (Easiest)

Just copy the URLs above and use them in your README:

```markdown
![LLM Guard Hero](https://image.qwenlm.ai/generated-images/38038c37-851d-4b51-9303-2d5de8aa8373/_result.png)
```

### Option 2: Download and Host Locally

1. **Download the images:**
   - Right-click each URL above
   - Save image as...
   - Save to `public/images/` folder

2. **Rename files:**
   ```bash
   # Hero banner
   mv [downloaded-file] public/images/hero-banner.png
   
   # Dashboard showcase
   mv [downloaded-file] public/images/dashboard-showcase.png
   
   # Logo
   mv [downloaded-file] public/images/logo.png
   ```

3. **Use in README:**
   ```markdown
   ![LLM Guard Hero](./public/images/hero-banner.png)
   ```

### Option 3: Upload to GitHub

1. Create `assets/` folder in your repository
2. Upload the images there
3. Reference them:
   ```markdown
   ![LLM Guard Hero](./assets/hero-banner.png)
   ```
